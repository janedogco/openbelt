# Third-party artwork

These marks identify compatible agents, services and hosts on the marketing page. They are
trademarks of their respective owners, not OpenBelt artwork. A collection's CC0 notice does not
replace an individual mark's license or trademark policy.

## Replaced from official sources

The November 2026 audit replaced the files below with unchanged owner-supplied artwork, except
Zed, whose existing geometry now uses the blue explicitly allowed by its brand guide.
The same source is used for both copies of Cursor and OpenAI.

| Files under `www/assets/`               | Source and treatment                                                                                                                                                                                                          |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agents/cursor.svg`, `logos/cursor.svg` | [Cursor brand kit](https://cursor.com/brand), `General Logos/Cube/SVG/CUBE_2D_DARK.svg`.                                                                                                                                      |
| `agents/devin.png`                      | [Devin brand kit](https://devin.ai/brand), [transparent white PNG](https://devin.ai/assets/brand/logos/devin/symbol-dark-transparent.png).                                                                                    |
| `agents/openai.svg`, `logos/openai.svg` | [OpenAI guidelines](https://openai.com/brand/), `OpenAI-white-monoblossom.svg` from [official ZIP](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip). OpenAI and its logo are trademarks of OpenAI. Used to identify Codex. |
| `agents/opencode.svg`                   | [OpenCode guidelines](https://opencode.ai/brand), [dark logo](https://opencode.ai/brand/files/opencode-logo-dark.svg), with its original proportions and surrounding space.                                                   |
| `agents/zed.svg`                        | [Zed guidelines](https://zed.dev/brand). Changed blue from `#084CCF` to `#1348DC`.                                                                                                                                            |
| `logos/github.svg`                      | [GitHub guidelines](https://brand.github.com/foundations/logo), `GitHub_Invertocat_White.svg` from the official GitHub ZIP above.                                                                                             |
| `logos/linear.svg`                      | [Linear guidelines](https://linear.app/brand), `logo-light.svg` from [official ZIP](https://static.linear.app/design-assets/Linear-Brand-Assets.zip?v=3).                                                                     |
| `logos/debian.svg`                      | [Debian Open Use Logo](https://www.debian.org/logos/), [unmodified SVG](https://www.debian.org/logos/openlogo-nd.svg), under CC BY-SA 3.0. See the notice below.                                                              |

AWS uses the inline SVG from [its official homepage](https://aws.amazon.com/), with its
`currentColor` wordmark displayed in white and its supplied orange smile unchanged.
Only the SVG attribute casing and whitespace were normalized.

Copilot was restored to its pre-audit mascot icon at the owner's request. GitHub's current
brand guide deprecates this artwork; it is no longer listed as an approved replacement here.

Devin uses the official transparent PNG instead of the SVG with an opaque black background.

The Copy prompt button uses the official light-background variants in
`agents/openai-on-light.svg` (`OpenAI-black-monoblossom.svg`),
`agents/cursor-on-light.svg` (`CUBE_2D_LIGHT.svg`) and
`agents/opencode-on-light.svg` ([supplied SVG](https://opencode.ai/brand/files/opencode-logo-light.svg)).
The dark-page variants remain in the logo rows.

The resolved hero marks use their actual SVG colors, without CSS masking or rotation.
Wide lockups retain their aspect ratios. Windsurf was subsequently removed at the owner's request. Stripe and Proxmox were restored to
their pre-audit icon artwork.
