# Glossary

OpenBelt's words. Use them in code, docs, UI copy and PR titles. Never use the _Avoid_ words.

**Workspace**: One company's shared place for its people, apps, data and connections. Workspaces never see each other.
_Avoid_: org, organization, tenant, team

**App**: What people and agents build: a folder of static files on its own host, with the shared SDK and its own data.
_Avoid_: site, mini-app, project

**Preview environment**: A named, separate set of data where apps run unreleased versions until promoted.
_Avoid_: preview (alone), staging, sandbox

**Live**: The version and data of an app that real people use.
_Avoid_: prod (that is OpenBelt's own server)

**Starter app**: A tested app anyone adds to their workspace in a second, with its first data: theirs to use, change or delete.
_Avoid_: template, sample app, demo app

**Gallery**: The workspace's home page; it lists its apps as cards.
_Avoid_: dashboard, main site, app store

**App frame**: The workspace's wrapper that opens an app with its panel.
_Avoid_: site frame

**Platform admin**: Whoever runs the OpenBelt server.
_Avoid_: operator, platform owner
